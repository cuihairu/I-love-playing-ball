# 第三版玩法设计:爱坤宗 · 主线章节制(Gameplay V3)

状态:v1 草案(2026-09-27)。定位:接替 `gameplay-v2.md` 的"广场制四艺合集"结构,改为**主线章节制**。v2 的四个玩法模块不废弃,作为 v3 的玩法原型与百戏楼自由模式内容回收(见 `levels.md` 隐藏章)。上游:`story.md`。Demo 三章细案配表(判定密度/帧数据/台词全量)见 `levels-demo-spec.md`。

## 为什么再推翻一次

- v2 是"玩法集合 + 轻包装",没有主线。热梗游戏生命周期短,叙事主线是把梗玩家转化为留存玩家的唯一抓手,也是 Steam 买断制的硬要求(买断制玩家买的是"一段完整的体验")。
- 新方向(2026-09 拍板):宗主被镇压、弟子化鸡、碎片收集、唤醒同门、每章不同玩法。v2 的四艺玩法自然降级为"章节玩法原型 + 隐藏章自由模式"。

## 核心系统

### 唤醒系统(主题即机制)

- 战斗胜利 ≠ 结束:BOSS 血条清空后进入"心魔剥离"阶段(特殊 QTE 或反向节奏段,接住他,不是打死他)。成功 = 唤醒。反向节奏段为 M1 轻量变体,难度阶梯(五拍起步,每章 +1,终章八拍)见 `levels.md` §1.1。
- 唤醒产出:人心灯(结局变量)+ 醒世报一份(收集品)+ 奖励(同伴入队/拳法传授/商店解锁/皮肤)。
- 杂兵小鸡唤醒:轻量版(靠近长按),凑数用途,维持"满山皆可救"的体验密度。

### 真香机制(NPC 通用唤醒流程)

三次互动拒绝 → 玩家完成一段反向节奏(他把"饿死不吃"唱回去)→ "……真香。"→ 入队。教学关:五章王生。所有可唤醒 NPC 统一走这条流程,扩展成本低(配表即上新 NPC)。2026-02 转折调参:支线盟友互动次数降为 2,教学关王生维持 3 次以保证完整教学(见 `levels.md` §1.1)。

### 人心灯与多结局

- 人心灯 24 满值,宽恕线阈值 10(2026-02 叙事转折下调,原 13),来源与配额见 `levels.md` §4。
- 宽恕线/心魔线两结局 + 隐藏独白,数值驱动,不做行为审判(UI 永远不告诉玩家"你选错了")。

### 宗拳格斗招式表(M2,初版)

- 基础:轻拳/重拳/轻脚/重脚四键 + 方向,起手三连、踏步肘两套入门连段。
- 防反:接化发(马老师传授,二章支线,精确格挡触发"我大意了啊,没有闪"演出,终章必需技能)。
- 必杀(人气槽满):闪电五连鞭(五段判定的全屏鞭击)、金鸡独立(上段无敌对空)。
- 觉醒技(残血一次):只因一击——画面瞬间只剩黑白两色,一击逆转。
- 对战对象:动物门派(鹅厂白鹅、鸭门双侠、犬吠帮、虎山派),动物性 = 攻击欲望与招式派系,不做真人指向性形象(合规红线,见 compliance)。

### 收集与图鉴

- 四宝碎片(主线)+ 律诏三卷 + 黑话图鉴 + 勋章墙(v2 继承)+ 醒世报八份 + 曲目"戏文考"。
- 梗素材全部走远端配置下发(compliance 既定工程对冲),图鉴词条可热更降敏。
