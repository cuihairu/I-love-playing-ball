# 合规分析(微信/抖音小游戏)

分析日期:2026-09-03。目标平台:微信小游戏(核心)、抖音小游戏。配合 `docs/meme-collection.md` 使用,玩法定稿时逐条对照本清单。

## 结论

按 ikun 梗的原始设定原样提审,大概率被平台驳回;即使侥幸过审,仍随时可能因权利人投诉被下架。风险按元素分层,玩法骨架安全,指向真人的形象与命名不安全。

## 平台规则依据

- 微信开放文档《平台运营规范》:名称、icon、简介、游戏内容未经授权不得使用第三方享有合法权益的商标、名称、肖像
- 抖音小游戏审核规范:图标使用人像需提供肖像权人授权证明
- QQ / TapTap / 快手规范同款条款:姓名权、肖像权、名誉权均在保护范围内
- 法律层面:《民法典》对姓名权、肖像权、名誉权的保护;商业化使用他人人格标识的暴露量级远高于个人玩梗

## 权利人行为记录

- 2019-04 蔡徐坤工作室向 B 站发律师函,指控故意诽谤、滥用肖像、侮辱性词汇;据界面新闻,触发函件的是暴力血腥 P 图和恶意侮辱内容,但"鸡你太美"系列本身在指控范围内
- 2025 起诉黑粉胜诉:该权利人有持续、成功的维权记录
- "鸡你太美"拼音 JINITAIMEI 已有海外商标抢注记录,梗词商用存在商标层风险

## 元素风险分级

| 元素 | 风险 | 原因 |
| --- | --- | --- |
| 游戏名含 坤 / ikun / 爱坤 / 鸡你太美 | 高 | 名称审核第一关直接指向真人。仓库内部命名不受影响,上线名不能用 |
| 背带裤+中分头+篮球+抖肩 组合形象 | 高 | 单个元素是普通物,组合起来构成该艺人舞台人格,指向性明确,实质等同未授权使用艺人形象 |
| 原曲仿写音乐 | 高 | 词曲著作权均受保护,空耳词属于改编;只能完全原创音乐 |
| "宗主"叙事指代真人 | 高 | 商业化使用他人人格标识 |
| 梗词文本(鸡你太美 / 只因 / 露出鸡脚) | 中 | 文本比形象风险低,但批量出现并配合视觉符号即构成指向性 |
| 骂人黑话(食不食油饼类谐音) | 中 | 谐音辱骂 + 未成年人保护敏感,游戏内文案必须二次改写 |

| 四艺修炼 + 格斗 + 收集玩法骨架 | 低 | 玩法机制不受保护也不侵权 |

## 关键认知:过审不等于安全

存在两道独立的关:平台机审与人审是一关,权利人投诉是另一关。微信对权利人投诉响应很快,2019 年一封律师函即可促成 B 站下架内容,小游戏下架流程更快。

"官方下场玩梗、同意二创"是舆论态度,不构成授权;口头开放不产生任何权利许可。

本项目的真实命题是梗的直白度与存活周期的权衡:梗越可识别,传播越强,下架风险越高。

## 路径选择(状态:待拍板,阻塞玩法定稿)

- 路径 A 全架空化:玩法骨架全留,IP 换原创鸡 + 原创宗门。过审稳,传播势能基本归零,等于换一个游戏
- 路径 B 降敏梗化(建议):砍掉全部高指向组合(名称、视觉签名、音乐),梗浓度降到圈内会意级:通用鸡脚动作、改写黑话、油饼道具,传播主力放在玩法本身的魔性上。中等风险,每个版本的素材需对照本文档清单过一遍
- 路径 C 硬上:按原始设定提审,被拒再改。每版驳回留记录,且过审后仍面临投诉下架,快钱逻辑,接受随时下架

## 工程对冲:梗浓度热更

不论选择哪条路径都建议执行:

- 梗素材全部走远端配置下发,复用后端素材配置接口
- 文案、表情、皮肤、梗词一律不进代码包
- 出现投诉或驳回时热更降敏,不需要重新提审
- 把"梗浓度"做成运营变量,而不是写死在客户端资产里

## 每版提审前检查清单

- 游戏名、简介、icon 无指向真人的词汇与形象
- 角色无"背带裤+中分头+篮球+抖肩"类指向性组合
- 全部音乐为原创,无原曲旋律或空耳歌词
- 文案中黑话谐音已二次改写,无辱骂性原始含义
- "教"系措辞已替换为"宗门"系
- 格斗败者演出无指向真人的羞辱性内容
- 梗素材已确认走远端配置,代码包内无硬编码梗资产

## Steam 发行补充(2026-09-27 增补)

背景:平台策略变更为 Steam 买断制先行(主线章节制叙事游戏,见 `story.md`/`levels.md`/`gameplay-v3.md`),微信/抖音小游戏后行。上文微信/抖音风险分析全部继续有效,微信版仍按路径 B 降敏执行。Steam 侧新增:

- Steam 国际版无版号可发行,但开发运营主体在境内,真人姓名权/肖像权/名誉权义务不因平台改变;权利人有 2019 律师函、2025 胜诉的持续维权记录,投诉-下架链路对 Steam 同样可用
- 蒸汽平台(Steam 中国)需版号,内容标准同国内平台:走蒸汽平台即全量按微信标准降敏
- 合规检查范围 = 商店页(名称/简介/宣传图/预告片)+ 游戏本体:愿望单页与预告片同样构成商业使用
- 上线名候选与风险分级见 `story.md` §8;内部代号与上线名分开管理

## 音乐/舞蹈/台词授权(2026-09-27 增补,配合 `levels.md` §3)

- 词曲:原曲一律禁用;AI 仿写交付前过"实质性相似"自检(不复现旋律主干,新旋律+新和声+新编曲),自检记录随资源入库
- 编舞:舞蹈作品受著作权保护;高指向性组合(抖肩+拍球+背带裤造型一类)是风险点,安全区 = 卡通鸡化 + 节拍错位魔改 + 公共舞种步型(jumpstyle/科目三等通用步型)
- 台词与声音:孙红雷诉《西瓜摊主大战买瓜人》案(2023,全国首例影视剧台词声音权纠纷,一审胜诉)确立台词声音可诉——玩梗台词全谐音改写,禁止任何原声采样
- 配音:禁止真人声音模仿与 AI 声音克隆,全部原创配音
- 本节并入每版上架前检查清单执行
