# 热梗语料收集与分析(ikun 梗)

收集时间:2026-08-31。用途:玩法设计、游戏内文案词库、角色与动画美术基准的统一素材库。玩法定稿过程中所有梗词、角色设定、勋章命名从这里取材,不重复搜。

## 1. 宗门/教派体系梗

| 梗 | 含义与用法 |
| --- | --- |
| ikun教 / 爱坤 | 粉丝群体被调侃成的"教派",游戏世界观的直接原型 |
| 宗主 | 网络对蔡徐坤的戏称,玩梗者自称"宗门弟子"。衍生语录:"宗主在外流浪,宗门日益兴隆""巅峰产生虚伪的拥护,黄昏见证虔诚的信徒""宗主才是全世界最不吃压力的男人" |
| 小黑子 | 反串黑粉:混在真爱粉里装 ikun。敌对 NPC 的天然设定 |
| 露出鸡脚 | 小黑子装粉时暴露身份,"露出马脚"的鸡化变体。经典台词:"小黑子,露出鸡脚了吧!不要做出任何和鸡有关的动作,不要发出任何和鸡有关的声音" |
| 全民制作人 | 开场白:"全民制作人们大家好,我是练习时长两年半的个人练习生" |
| 两年半 | 练习时长,万能数字梗。"练习没有两年半一律不收入" |

## 2. 四艺本体梗

| 梗 | 用法 |
| --- | --- |
| 唱、跳、rap、篮球 | 自我介绍四特长,四个修炼渠道的原文出处 |
| 只因你太美 → 鸡你太美 | 空耳梗,识别度最高;"只因"="鸡"的万能替换字 |
| 你干嘛~哎哟 | 经典音频梗,适合受击/失误音效 |
| Music! | 开场白结尾,可做对局开始号令 |

## 3. 视觉符号梗

- 背带裤(白)
- 中分头
- 篮球
- 抖肩舞步
- 鸡脚:露出鸡脚、鸡脚在弹
- 油饼:道具化潜力最大

这套符号经萌娘百科词条和多年鬼畜二创验证,抽象成卡通小鸡后识别度依然成立。

## 4. 黑话谐音梗

| 黑话 | 真实含义 |
| --- | --- |
| 食不食油饼 / 油饼食不食 | "是不是有病" |
| 香翅捞饭 | "想吃牢饭" |
| 精煎鱼食不食 | "经验教训是不是" |
| 耗丸 | "好玩" |
| 鸡脚卤出来啦 | "露出鸡脚"变体 |
| 披金成王,伴坤远航 | ikun 应援语录 |

完整段子库参考:知乎《ikun 开团段子合集》(分类:露出鸡脚类、藏头露尾类、谐音梗小故事类、妙评神评类、押韵诵诗类、ikun 语录类)和 CSDN《ikun 必会的口号》。

游戏内使用原则:含脏话谐音的词条(食不食油饼、香翅捞饭)必须二次改写后再入文案。

## 5. 生命周期状态(2026-08)

- 宗主梗处于活跃期:抖音"宗主没了宗门还在"系列 2026-08 仍在更新
- 官方亲自下场:蔡徐坤时隔七年直播回应玩梗、同意二创鬼畜、主动 cue 篮球梗;新歌 What a Day 配 jumpstyle 舞被二创为"宗主第二招",梗仍在产新内容
- 2025-04 胜诉事件:"恭迎宗主回归""七年玩梗,九年官司"带来新热度
- 萌娘百科预计相关梗可流行到 2029 年:2029 为鸡年,是天然的续命节点和营销日历
- 风险提示:有观点认为换字玩梗(鸡/黑互换)意味着梗进入后半段,但宗主/宗门体系是当前的增长点

## 6. 分析:梗到游戏的映射

### 角色群像

每只卡通小鸡对应一个梗身份:

- ikun 小鸡:背带裤 + 中分头 + 篮球,玩家形象
- 小黑子鸡:乌鸦黑鸡,敌对 NPC
- 全民制作人鸡:观众/评委席
- 宗主鸡:永不露全脸的传说皮肤

真人形象、真名、原曲一律不用,全部卡通鸡化 + 谐音改写。

### 露出鸡脚 = 核心机制

梗文化里"露出鸡脚"是暴露身份的瞬间,天然是游戏性语言:

- 节奏玩法:伴舞小鸡鸡脚在弹,完美判定给鸡脚特写
- 对抗玩法:对手小黑子周期性露出鸡脚,抓鸡脚露出的时机出招才有暴击

### 勋章与黑话图鉴

- 每个玩法发一类梗勋章:节奏玩法发鸡脚勋章(铜/银/金),格斗争霸发油饼勋章
- 收集册做成黑话图鉴:集齐"食不食油饼""香翅捞饭"等词条点亮图鉴,收集行为即"入教"仪式

### 对局结构

- 单人 = 修炼线:四艺各玩法 + 小黑子 NPC
- 双人 PK = 实时对战:WebSocket 连接,服务端裁决

### 战略节点

- 梗系有官方背书 + 持续产新 + 2029 鸡年节点,不是普通短命热梗
- 设计上保留"梗图鉴可持续更新"的口子,2029 鸡年做大版本

### 合规红线

- 不出现真人姓名、肖像、原曲
- 全部梗词用谐音改写版本(鸡你太美 → 机你太美级别),规避审核敏感词
- 官方对二创开放降低的是舆论风险,不降低平台审核风险
