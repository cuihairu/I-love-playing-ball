## 1. 世界观设定

### 1.1 爱坤宗·旧闻
- **宗主·坤坤**：本名「练习时长两年半的个人练习生」，因一曲《只因你太美》+ 背带裤篮球舞，意外开启「鸡你太美」时空裂隙，成为跨维度梗文化图腾。
- **四大护法**（对应四艺）：
  - **舞娘·背带裤** —— 掌管「律动之力」，化身节奏战场
  - **球圣·橙球** —— 掌管「轨迹之力」，化身街篮对决
  - **拳皇·闪电五连鞭** —— 掌管「刚毅之力」，化身格斗擂台
  - **鸣鸡·鸡腿** —— 掌管「觉醒之力」，化身叙事终局

### 1.2 心魔大阵·镇压真相
| 时间线 | 事件 | 游戏隐喻 |
|--------|------|----------|
| 2019.01 | NBA 新春大使视频发布 → B站鬼畜区「血洗」 | **开天辟地·梗诞生** |
| 2019-2022 | 抽象文化扩散，「鸡你太美」成全民符号 | **心魔滋生·黑粉化作「迷雾鸡」** |
| 2023.06 | 江小宴/超能摄影阳阳爆料「堕胎门」 | **心魔爆发·宗主被镇压，四护法碎片散落** |
| 2023.07 | 央视频/豆瓣下架，工作室经营异常 | **宗门封山·弟子化身「迷途小鸡」** |
| 2024-2025 | 多次庭审，造谣者认罪道歉，胜诉 | **觉醒曙光·碎片可拾，小鸡可醒** |
| 2025.04 | 判决书公开，赔偿款捐公益 | **真神归来·大团圆结局** |

> **核心隐喻**：现实中「黑粉→真粉」的转化曲线，映射为游戏中「迷雾鸡→觉醒鸡」的净化流程。

## 3. 角色系统

### 3.1 主角：觉醒小鸡（玩家化身）
- **初始形态**：灰白羽毛、半闭眼、脖子歪（被洗脑状态）
- **觉醒进程**：收集碎片 → 羽毛变色（灰→黄→金）→ 解锁技能槽
- **三维属性**：
  - **律动** → 节奏关判定窗口/连击加成
  - **轨迹** → 投篮弹道显示/格斗取消帧优势
  - **刚毅** → 格斗护甲/受击减速抗性
  - **觉醒** → 对话选项解锁/结局分支权重

### 3.2 师兄弟（NPC/可唤醒同伴）
| 类型 | 外观 | 被洗脑台词 | 唤醒条件 | 觉醒后功能 |
|------|------|------------|----------|------------|
| **迷雾鸡** | 灰色、眼神空洞、重复「鸡你太美」 | 「偶像毫无实力」「营销号附体」 | 击败关卡BOSS + 选「唤醒」 | 变身「觉醒鸡」，驻扎大本营提供Buff |
| **叛逆鸡** | 红眼、周身黑雾、主动攻击玩家 | 「别装了」「早晚塌房」 | 连续完美通关2次同关卡 | 解锁「黑化皮肤」+ 高难度模式 |
| **路人鸡** | 普通黄鸡、旁观鼓掌 | 「吃瓜」「不知道」 | 送礼（碎片/道具） | 提供世界观补完日志 |

### 3.3 宗主·坤坤（最终解锁可操作角色）
- **解锁条件**：通关标准结局 + 收集所有隐藏日志
- **专属机制**：「C位光环」—— 全队共享连击数，「只因你太美」BGM 常驻
- **终极技**：「鸡年大吉」—— 全屏节奏判定，敌人强制跟随节拍受击

## 4. 叙事表现手法

### 4.1 环境叙事
- **碎片回响**：捡起碎片触发 5-10 秒「记忆碎片」（像素风动画/语音/聊天记录还原）
- **墙壁涂鸦**：关卡背景藏「超能摄影阳阳」「懂瓜呱」「江小宴」等 ID 的涂鸦，交互弹出法庭判决书片段
- **BGM 演变**：同一旋律《只因你太美》在不同关卡变奏：
  - 迷雾版（失真/慢速/反向）→ 净化版（钢琴/弦乐）→ 觉醒版（摇滚/电子/合唱）

### 4.2 对话系统
- **关键词链接**：对话选项含「梗关键词」（如「两年半」「闪电五连鞭」「你干嘛哎呦」），触发隐藏分支
- **黑粉→真粉转化日志**：每唤醒一只迷雾鸡，大本营「觉醒墙」新增一条真实网友转粉见证（爬取公开评论脱敏）

### 4.3 多结局判定
| 结局 | 条件 | 核心旁白 |
|------|------|----------|
| **坏结局** | 碎片收集<60%，未唤醒核心师兄弟 | 「心魔未除，梗归虚无」 |
| **标准结局** | 全碎片+主线通关 | 「真神归来，爱坤宗重光」 |
| **真结局** | 全收集+隐藏关+所有师兄弟唤醒 | 「鸡年飞升，每个被误解的灵魂都能找到回家的路」 |
| **抽象结局** | 故意全关卡「完美失误」（0分通关） | 「若干年后，考古学家发现一块刻着『只因你太美』的石碑……」 |

## 5. 梗文化合规化处理原则

| 原始素材 | 游戏化转化 | 规避风险点 |
|----------|------------|------------|
| 「鸡你太美」空耳 | 设定为「远古咒语/频率共振」 | 避免直接播放原版音频，自制变奏版权曲 |
| 蔡徐坤真实面容/姓名 | 仅以「宗主」「坤坤」代称，美术风格化（Q版/像素/抽象） | 不使用真实肖像、姓名、声线，规避肖像权/姓名权 |
| 2023 造谣事件 | 抽象为「心魔·造谣巨兽」，台词泛化为「捏造事实」「以讹传讹」 | 不复述具体指控细节，不展示当事人真实信息 |
| 法院判决文书 | 转化为「天道判令」道具，文本重写为通用法理语言 | 不直接展示真实判决书截图 |
| 黑粉/真粉对立 | 转化为「迷雾/觉醒」阵营，强调「认知觉醒」而非人身攻击 | 移除一切人身攻击、地域歧视、性别对立语言 |

> **红线**：零容忍任何可识别真实自然人的贬损表达；所有梗仅保留「符号/结构/节奏」，剥离「指涉对象」。
