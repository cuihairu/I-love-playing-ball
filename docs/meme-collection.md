## 1. 宗门/教派体系梗

| 梗 | 含义与用法 |
| --- | --- |
| ikun教 / 爱坤 | 粉丝群体被调侃成的"教派",游戏世界观的直接原型 |

## 6. 分析:梗到游戏的映射

### 角色群像

每只卡通小鸡对应一个梗身份:

- ikun 小鸡:背带裤 + 中分头 + 篮球,玩家形象
- 小黑子鸡:乌鸦黑鸡,敌对 NPC
- 全民制作人鸡:观众/评委席
- 宗主鸡:永不露全脸的传说皮肤

真人形象、真名、原曲一律不用,全部卡通鸡化 + 谐音改写。

### 露出鸡脚 = 核心机制

梗文化里"露出鸡脚"是暴露身份的瞬间,天然是游戏性语言:

- 节奏玩法:伴舞小鸡鸡脚在弹,完美判定给鸡脚特写
- 对抗玩法:对手小黑子周期性露出鸡脚,抓鸡脚露出的时机出招才有暴击

### 勋章与黑话图鉴

- 每个玩法发一类梗勋章:节奏玩法发鸡脚勋章(铜/银/金),格斗争霸发油饼勋章
- 收集册做成黑话图鉴:集齐"食不食油饼""香翅捞饭"等词条点亮图鉴,收集行为即"入教"仪式

### 对局结构

- 单人 = 修炼线:四艺各玩法 + 小黑子 NPC
- 双人 PK = 实时对战:WebSocket 连接,服务端裁决

### 战略节点

- 梗系有官方背书 + 持续产新 + 2029 鸡年节点,不是普通短命热梗
- 设计上保留"梗图鉴可持续更新"的口子,2029 鸡年做大版本

### 合规红线

- 不出现真人姓名、肖像、原曲
- 全部梗词用谐音改写版本(鸡你太美 → 机你太美级别),规避审核敏感词
- 官方对二创开放降低的是舆论风险,不降低平台审核风险

## 10. 坤拳梗源(2026-10-04 增补,武学体系溯源)

> 「坤拳」是源于蔡徐坤相关网络迷因的恶搞武术梗,核心是将其标志性舞蹈动作魔改"拳法",是"小黑子"(玩梗群体)的趣味二创,**无真实武术意义**。

- **起源与核心关联**:基础来源=2019《偶像练习生》自我介绍"喜欢唱跳rap篮球"+篮球舞,被鬼畜区二次创作后"坤"成代称;梗化关键=粉丝与玩梗者冲突后,UP主"悠悠球琛总"道歉视频整活,推动"坤舞""坤拳"教程类二创爆发,"坤拳"正式出圈。
- **梗内容与招式**:设定为"只因派"绝学,需"练习两年半",融合篮球舞、铁山靠、擒拿等,配"食油饼""荔枝"等黑话;经典招式:左右摇摆(晃肩)、前仰跳投(篮球动作)、铁山靠(顶肩)、化坤手(wave 手势),乃至"汤姆老师""马大师败北"等搞笑设定。
- **游戏名目映射**(`docs/kunquan-system.md`):坤山靠←铁山靠魔改;化坤手←wave 手势招式化;马宗主/马老师←"马大师败北"系(马保国梗,另有闪电五连鞭条);壳上「只因」/两年半计量←只因派/练习两年半;"食油饼"已入道具表(油饼=护盾)。
- **传播与现状**:鬼畜视频、直播整活、小说/游戏(如《暴走英雄坛》)衍生;恶意减弱,成"小黑子"接头暗号,粉丝与玩梗者和解,"你干嘛""两年半"等同系列梗常配套出现。
- **合规注记**:非真实拳法,纯娱乐符号——本作武学全架空魔改(与 compliance 零真人红线一致),公开场合使用注意场合避免冒犯;游戏内名目不与真人形象组合。

## 11. 黑话词条增补(2026-10-04,鸡杂系)

- **鸡杂**:**杂役弟子的名称**——做舔狗、不爱自己的,都会被笑为"鸡杂"。世界观落点:宗门内外的杂役弟子称谓,兼作小黑子语系嘲讽词(蜚语阁/妄言海骂称池+黑话图鉴词条);主题挂点=「不爱自己」与五章怠惰茧潮、随大流暗线互文。合规:称谓/骂称属降敏面(微信版词条替换池),嘲讽对象是"舔狗行为"而非具体人群。
- 孙学、薄肌:**不引入**(2026-10-04 用户裁定)。
