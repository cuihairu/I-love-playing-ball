# 第二版玩法设计:爱坤宗 · 四艺修行

## 为什么推翻第一版

第一版是"篮球小游戏贴小鸡皮",玩法核心押在投篮手感上,梗只是装饰。

热梗游戏的成立公式不一样:

- 3 秒看懂,梗即玩法本身
- 失败即内容,有必须晒出去的瞬间
- 比的是上线速度和梗密度,不是玩法深度

"唱、跳、rap、篮球"是梗的原文。把这四个字直接做成四个玩法模块,梗和玩法合一,不再需要贴皮。

## 核心概念

游戏世界是一个宗门:爱坤宗。

- 玩家是初入门墙的练习生,目标是修成四艺、挑战宗主之位
- 宗主从不露真容,只在关键节点"显圣"(全屏梗图演出)
- 宗门四艺对应四个玩法入口:唱、跳、rap、篮球
- 宗门主页就是游戏首页:广场上立四扇修炼室的门

一句话卖点:在爱坤宗修炼唱跳rap篮球,练满两年半,挑战宗主之位。

## 核心循环

1. 进入宗门广场,选择一门修炼
2. 完成一局该修炼渠道的玩法
3. 获得修炼时长、勋章进度、段位分
4. 修炼等级提升,解锁新的曲库、皮肤、修炼渠道
5. 勋章墙更新,生成梗图分享卡片
6. 循环,直到四艺大成,解锁"挑战宗主"终极演出

## 四大修炼渠道

| 渠道 | 玩法原型 | 引擎 |
| --- | --- | --- |
| 唱 | 节奏大师式下落音轨 | 节奏引擎 |
| 跳 | 手势方向轨跟舞 | 节奏引擎 |
| rap | 弹幕拦截快嘴对决 | 节奏引擎 |
| 篮球 | 街头争霸投篮对决 | 现有蓄力投篮代码 |

### 唱 · 节奏殿堂

- 下落式音轨,挑战宗门曲库
- 曲库全部 AI 仿写梗曲,严禁使用原曲
- 判定分层:PERFECT / GOOD / MISS,判定词用梗:PERFECT 弹"食不食油饼",MISS 弹"小黑子刷差评"
- 连击提升时,旁边小鸡的伴舞动作跟着升级(联动跳艺的表现层)
- 每首歌按星级评级,通关解锁下一首

### 跳 · 伴舞台

- 手势方向轨:上下左右滑动跟跳,段落式编舞
- 高难度段落出现"记忆编舞":先演示一遍,玩家复现
- 复用节奏引擎,只是轨道类型从"点击"换成"手势"

### rap · 快嘴对决

- 小黑子弹幕随节拍飞来,玩家在判定线上点击"接住韵脚"反击
- 密度随难度提升,本质是节奏引擎的弹幕变体
- 反击成功触发 diss 梗词弹出

### 篮球 · 街头争霸

- 非同步 1v1:与随机对手的记录对抗,各投各的 60 秒,分数高者胜
- 段位晋级赛对手是小黑子街球 NPC:街头球混子 → 巷子之王 → 宗门球魁
- 复用现有 `ShotInputController` 和 `GameplaySession`,蓄力投篮代码不浪费
- 后续可接微信"社交擂台赛"组件做真异步对抗

## 修炼与解锁

- 修炼等级即进度,计量单位用"天",成就叫"两年半"
- 等级解锁顺序:开局开放唱、篮球两艺,跳和 rap 的入口立"此艺修炼中"的牌子
- 牌子本身就是梗:点开提示"此艺尚未修炼两年半,敬请期待"
- 段位阶梯:练习生 → 外门弟子 → 内门弟子 → 真传弟子 → 长老 → 宗主亲传 → 挑战宗主

## 勋章体系

四艺各一条勋章树,按里程碑发放:铜 / 银 / 金。

梗勋章作为隐藏收集:

- 初见宗主
- 全民制作人们
- 小黑子克星
- 食不食油饼
- 律师函传人
- 两年半

勋章墙就是玩家主页,主页即分享卡片:小鸡形象 + 勋章墙 + 段位,一键生成梗图。

参考抓大鹅的稀缺感设计:限定梗勋章限时投放,不鼓励速刷,制造"差一枚"的收集焦虑。

## 广告点位

以激励视频为主,插屏只放在局与局之间:

- 各模式失败复活(唱续唱、篮球加时)
- 离线修炼收益翻倍
- 曲库 / 皮肤解锁
- 每日参拜宗主:看广告领随机奖励
- 勋章分享卡片去水印

不对局过程中硬插广告。

## 页面结构

- 宗门广场(首页):四扇修炼室的门 + 勋章墙入口
- 各修炼室(对局页):四艺各一套
- 挑战结果(结算页):分数、段位变化、勋章进度、复活按钮
- 勋章墙(收集页):勋章 + 分享卡片生成
- 宗主殿(终极演出页):四艺大成后解锁

## 分期落地

### V1

- 宗门广场 + 唱 · 节奏殿堂 + 篮球 · 街头争霸
- 跳、rap 入口做"修炼中"牌位(控制范围,同时是梗)
- 修炼等级、四艺勋章树、8 枚以上梗勋章
- 分享卡片、结算复活广告位、每日参拜
- 后端沿用现有排行榜接口,按渠道分榜

### V2

- 跳 · 伴舞台、rap · 快嘴对决
- 篮球段位晋级赛 NPC 阶梯
- 限定梗勋章限时活动

### V3

- 挑战宗主终极演出
- 微信社交擂台赛组件、好友对抗

## 工程要点

- 节奏引擎只做一套:轨道类型参数化(点击 / 手势 / 弹幕),唱、跳、rap 三艺复用
- 篮球艺复用现有 gameplay 模块,scene 层套街头争霸壳
- 每艺的数值全部进 `packages/game-config`,按 `gameplay.v2.rhythm.json`、`gameplay.v2.basket.json` 分文件
- 勋章、等级、解锁状态走本地存储 + 后端排行榜提交

## 合规红线

- 不出现真人姓名、真名谐音直接指代、真人肖像
- 宗主形象 = 卡通小鸡 + 传说皮肤,皮肤设计做谐音化的视觉玩笑,不直接复刻标志性造型
- 曲库全部 AI 仿写,不上传任何原曲音频
- 全部梗词使用谐音改写版本,规避审核敏感词

## V1 验收标准

- 宗门广场四入口可见,其中两个可玩、两个显示"修炼中"
- 节奏殿堂至少 3 首可玩曲目,有 PERFECT / GOOD / MISS 判定和连击
- 篮球街头争霸可完成一局非同步对抗
- 修炼等级可累计,等级提升有全屏反馈
- 勋章不少于 8 枚,勋章墙可生成分享卡片
- 至少 2 个激励视频复活点位可跑通占位流程
- 结算后可提交排行榜并回显
